Nota: la historia 1 (infraestructura) es prerequisito de las historias 2-4 (piloto quotes) — se separan porque la infraestructura debe ser verificable de forma independiente (compila, sin consumidores) antes de que el piloto la consuma.

## Why

Los 13 documentos PDF del sistema (`billing`, `quotes`, `payments`, `inventory`, `reports`) se generan hoy con `@react-pdf/renderer` sin ninguna base compartida: cada módulo mantiene su propio `pdfStyles.ts` con colores arbitrarios (azul `#1565C0`, grises sueltos `#ccc`/`#999`/`#666`, rojo `#c00`) que no corresponden a la paleta de marca ya definida en `tailwind.config.ts` (Material 3 "Agro-Systemic"), y ningún PDF renderiza el logo del negocio pese a que `billing/pdfStyles.ts` ya tiene un estilo `logo` muerto sin usar. Además hay duplicación real de código: `payments/pdfStyles.ts` e `inventory/pdfStyles.ts` son casi idénticos, `quotes` y `billing` comparten estructura, y el formateo de moneda se reimplementa 4 veces por separado. Este change es el primero de una secuencia de 4 (según plan aprobado): construye la infraestructura compartida sin tocar nada existente, y la valida migrando `quotes` como piloto de bajo riesgo antes de tocar módulos más sensibles (billing, con su watermark fiscal) o de mayor volumen (reports, con 8 documentos).

## What Changes

- Se crea `src/shared/infrastructure/pdf/pdfTheme.ts` con constantes hex portadas 1:1 de `tailwind.config.ts` (primary, tertiary, outline, outlineVariant, surfaceContainer/-High/-Low, onSurface/-Variant, error, errorContainer), reemplazando el uso de `#c00` por el rojo de marca `#ba1a1a`.
- Se crea `src/shared/infrastructure/pdf/pdfBaseStyles.ts` con fragmentos de estilo genuinamente compartidos (page, tableHeader, tableRow/tableRowAlt, banda de totales, footer, badge, bordes) como objeto plano componible vía `StyleSheet.create({...pdfBaseStyles, ...propio})`.
- Se crea `src/shared/infrastructure/pdf/resolvePdfLogoSource.ts` + `PdfLogo.tsx`: resuelve un `logoUrl` (URL https del tenant, o fallback local `public/logo.png` vía ruta absoluta/Buffer — nunca una ruta relativa tipo browser, que no resuelve del lado servidor) y expone un componente `<PdfLogo>` reutilizable.
- Se crea `src/shared/infrastructure/pdf/pdfIssuer.ts` con el tipo `PdfIssuer` (superset de `QuotePdfIssuer` + `logoUrl`) y el helper `toPdfIssuer(settings: TicketSettings): PdfIssuer`.
- Se crea `src/shared/infrastructure/formatters/formatPdfCurrency.ts`, reemplazando las 4 implementaciones duplicadas de `Intl.NumberFormat("es-MX", {style:"currency",...})` en `QuotePdf.tsx`, `InvoiceDocumentPdf.tsx`, `AnticipoReceiptPdf.tsx`, `DepartmentPriceListReportPdf.tsx` (esta migración de los 3 archivos fuera de `quotes` se hace en este change solo para el formateador, ya que es un cambio mecánico de bajo riesgo; el resto de cada uno de esos módulos se migra en su change correspondiente).
- Se crea un helper puro `rowStyle(index, base, alt)` para reemplazar el patrón `idx % 2 === 0 ? s.tableRow : s.tableRowAlt` repetido 14+ veces.
- Se migra `quotes/infrastructure/pdf/pdfStyles.ts` para componer `pdfBaseStyles` + `pdfTheme` en vez de definir sus propios hex.
- Se extiende `QuotePdfIssuer` con `logoUrl: string | null`, y `QuotePdf.tsx` renderiza `<PdfLogo>` en el header.
- Se actualiza `QuotesController.ts` (línea ~165) para incluir `logoUrl` al construir el issuer que se pasa al PDF, usando `toPdfIssuer`.

## Capabilities

### New Capabilities
- `pdf-design-system`: infraestructura compartida de estilos/colores/logo/formateo para generación de documentos PDF con `@react-pdf/renderer`, reutilizable por todos los módulos que generan PDFs.

### Modified Capabilities
- `quotes-api`: el PDF de cotización (`GET /api/v1/admin/quotes/:id?format=pdf`) ahora incluye el logo del negocio en el header y usa la paleta de colores de marca en vez de colores arbitrarios.

## Impact

- **Archivos nuevos**: `src/shared/infrastructure/pdf/{pdfTheme.ts, pdfBaseStyles.ts, resolvePdfLogoSource.ts, PdfLogo.tsx, pdfIssuer.ts}`, `src/shared/infrastructure/formatters/formatPdfCurrency.ts`.
- **Archivos modificados**: `src/modules/quotes/infrastructure/pdf/{QuotePdf.tsx, pdfStyles.ts}`, `src/modules/quotes/infrastructure/http/QuotesController.ts`, y los 3 call sites de moneda fuera de quotes (`src/modules/billing/infrastructure/pdf/InvoiceDocumentPdf.tsx`, `src/modules/reports/infrastructure/pdf/AnticipoReceiptPdf.tsx`, `src/modules/reports/infrastructure/pdf/DepartmentPriceListReportPdf.tsx`) — solo la línea de formateo de moneda, sin tocar el resto de esos archivos.
- **Sin cambios de esquema de base de datos.**
- **Sin cambios de API pública** (mismo endpoint, mismo formato de respuesta, mismo `Content-Disposition`) — solo cambia el contenido visual del PDF de cotizaciones.
- **Dependencias**: ninguna nueva; sigue usando `@react-pdf/renderer` ya instalado y `GetTicketSettingsUseCase` ya existente.
